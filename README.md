# 🎀 Kawaii Corner — Sanrio Merch Shop

Sklep internetowy z oficjalnym merchem Sanrio zbudowany jako projekt szkolny.

## O projekcie

Strona sklepu z postaciami Sanrio (Hello Kitty, Kuromi, Cinnamoroll i inne). Użytkownik może przeglądać produkty, filtrować je po kategorii i typie, wyszukiwać, dodawać do koszyka i składać zamówienia. Strona dostępna po polsku i angielsku.


## Funkcje

-  Rejestracja i logowanie (hasła bcrypt, sesje PHP)
-  Koszyk dostępny tylko po zalogowaniu
-  Wyszukiwarka i filtry produktów
-  Kolory strony zmieniają się wraz z kategorią
-  Zmiana języka PL / EN
